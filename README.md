# Alienware Arena Fixer

CORS proxy for Alienware Arena in an attempt to fix Twitch quests, since sometimes preflight requests cause the server to return 404s or 500s.

> [!NOTE]
> This only fixes the Twitch panel loading in your browser. It does not and cannot fix Alienware Arena backend behavior like wrong earn rates or incorrect ARP calculation.
